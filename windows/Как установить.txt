МАРШРУТНЫЙ ЛИСТ — установка на Windows

1. Распакуй архив в отдельную папку, например «Документы\Маршрутный лист».
   В эту же папку программа будет сохранять маршрутные листы и PDF
   с документами — по папкам на каждый день.

2. Запусти «Маршрутный лист.exe».
   Если Windows покажет синее окно «Windows защитил ваш компьютер» —
   нажми «Подробнее» → «Выполнить в любом случае».

3. При первом запуске программа попросит токен МоегоСклада:
   МойСклад → Настройки → Токены → «Создать токен».
   Скопируй его целиком, вставь в окно и нажми «Проверить и сохранить».
   Галочка «Создать ярлык на рабочем столе» сделает ярлык для запуска.

4. Токен хранится только на этом компьютере, в файле config.ini рядом
   с программой, — никому этот файл не пересылай.

Обновления приходят сами: при запуске программа проверяет новую версию
и обновляется (файл marshrut.py рядом с exe). Скачивать заново не нужно.
Сменить токен можно кнопкой «Настройки» в правом верхнем углу.
