# Маршрутный лист для МоегоСклада

Программа для «Папирус Алтай»: берёт отгрузки за день из **МоегоСклада** и за пару минут
готовит всё, что нужно водителю и складу, — без ручного переноса данных.

|---|---|

Скачивать заново при каждом обновлении не нужно — программа обновляется сама при запуске.

## Что умеет

- **Маршрутный лист в Excel** — все отгрузки за выбранный день: номер, контрагент, адрес,
  комментарий к доставке, товары. Внизу — сводка для производства и сколько наличных
  водитель должен привезти.
- **Количество в упаковках и штуках** — неважно, чем оформили реализацию:
  «2 уп (24 шт)», «2 уп + 6 шт (30 шт)». Пересчёт по фасовке из карточки товара.
- **Оптимальный порядок доставки** — расставляет точки по маршруту с учётом времени работы
  («до 16:00», «с 10:30») и даёт ссылку на маршрут в Яндекс Картах.
- **Доставка или командировка** — тип выезда сразу попадает в название файла.
- **«Загрузка» для начальника производства** — отдельный лист под подпись водителя.
- **Документы на печать одним PDF** — УПД, расходные накладные, счета, ТТН — в порядке маршрута.
- **Всё раскладывается по папкам** — на каждый день своя папка с датой.

## Установка

### Windows
1. Распакуй архив в отдельную папку, например «Документы\Маршрутный лист».
2. Запусти «Маршрутный лист.exe». Если Windows покажет «Windows защитил ваш компьютер» —
   «Подробнее» → «Выполнить в любом случае».
3. Вставь токен МоегоСклада (см. ниже).

### Mac
1. Распакуй архив и перенеси папку «Маршрутный лист», например, в «Документы».
2. Нажми на «Установить.command» **правой кнопкой** → «Открыть» → «Открыть».
   Если Python ещё не установлен, откроется python.org — установи его и запусти файл снова.
3. Дальше программа запускается файлом «Маршрутный лист.command».
4. Вставь токен МоегоСклада (см. ниже).

### Токен МоегоСклада
МойСклад → **Настройки** → **Токены** → **«Создать токен»**. Скопируй и вставь в окно программы
при первом запуске. Если пункта «Токены» нет — попроси администратора дать доступ к API.

## Безопасность

- **Токен хранится только на твоём компьютере** — в файле `config.ini` рядом с программой.
  В этом репозитории его нет и быть не может. Никому не пересылай `config.ini`.
- **Данные никуда не уходят.** Программа обращается только к:
  - `api.moysklad.ru` — отгрузки и печатные формы;
  - OpenStreetMap — найти адреса доставки на карте (уходит только текст адреса);
  - OSRM — время в пути между точками (только координаты);
  - GitHub — проверить, нет ли новой версии.
- **Обновление** скачивается только из этого репозитория по защищённому соединению.
  Перед заменой программа проверяет, что файл целый; прошлая версия сохраняется
  рядом как `marshrut.py.old`.
- Отключить автообновление: в `config.ini` добавь
  ```
  [update]
  auto = no
  ```

## Если что-то не работает

- Ошибки пишутся в файл `ошибки.log` в папке программы — пришли его разработчику.
- «Не нашёл адрес на карте» — впиши адрес проще или вставь координаты/ссылку из Яндекс Карт:
  программа запомнит точку.

---

Для разработчика: программа — `marshrut.py` (Python, customtkinter). Новая версия выходит,
когда в `marshrut.py` и `version.txt` меняется номер `BUILD`. Установочные архивы
собираются автоматически (GitHub Actions) при добавлении метки `v…`.
