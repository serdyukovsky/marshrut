МАРШРУТНЫЙ ЛИСТ — установка на Mac

1. Перенеси эту папку туда, где программа будет жить, например в «Документы».
   Там же она будет сохранять маршрутные листы и PDF с документами.

2. Нажми на «Установить.command» ПРАВОЙ кнопкой мыши → «Открыть» → «Открыть».
   (Обычный двойной клик macOS не даст: программа не из App Store.)
   Если Python ещё не установлен, откроется сайт python.org — установи
   Python и снова запусти «Установить.command».

3. Дальше программа запускается файлом «Маршрутный лист.command».
   Его можно перетащить в Dock для быстрого запуска.

4. При первом запуске программа попросит токен МоегоСклада:
   МойСклад → Настройки → Токены → «Создать токен».
   Токен хранится только на этом компьютере, в файле config.ini, —
   никому этот файл не пересылай.

Обновления приходят сами: при запуске программа проверяет новую версию.
